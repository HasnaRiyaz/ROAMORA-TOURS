# Serendib Escape — Sri Lanka Tourism Frontend

A modern, immersive Sri Lanka tourism landing page built for VS Code.

## Stack
- React 19
- Vite
- Modern CSS (glassmorphism, responsive layouts, CSS animation)
- Lucide React icons
- Swiper is included in dependencies for future carousels

## Run in VS Code

1. Install Node.js 20+.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run:

```bash
npm install
npm run dev
```

5. Open the localhost URL shown by Vite.

## Where to customise

- `src/main.jsx` → page sections, text, places and interactions.
- `src/styles.css` → all visual styling and responsive design.
- Replace the Unsplash image URLs with your own Sri Lankan photography/video assets for production.
